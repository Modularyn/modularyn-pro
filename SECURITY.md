# Security

## Reporting a vulnerability

Report a security problem in this repository privately, never in a public issue or pull request. Use GitHub's private vulnerability reporting: on this repository's **Security** tab, choose **Report a vulnerability**. If you cannot use it, email modularyn@jasonfurr.com.

Say what you found, the release or commit it affects, its potential impact and how to reproduce it, with sensitive data removed. The maintainer reads every report. Modularyn has no support commitment yet, so no response time is promised.

## What this covers

This policy covers the source in this repository and any release published from it. Nothing has been released yet.
