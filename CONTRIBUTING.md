# Contributing to Modularyn Pro

Modularyn Pro takes no outside contributions. Its source is published for review under the PolyForm Noncommercial License 1.0.0, and pull requests from outside are not accepted.

Bug reports and feature requests about the Community edition belong in [Modularyn/modularyn](https://github.com/Modularyn/modularyn/issues). The organization's [contributing guide](https://github.com/Modularyn/.github/blob/main/CONTRIBUTING.md) describes how to write a good report.

Never report a vulnerability in a public issue or pull request; see [SECURITY.md](SECURITY.md).
